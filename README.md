# Tapir

Десктопний додаток для запису інтернет-радіо з повною доступністю для незрячих користувачів.

**Платформа:** Windows 11+ · Portable EXE  
**Стек:** Tauri v2 · React 19 · React Aria · Rust  
**Скрінрідери:** NVDA · JAWS · Narrator

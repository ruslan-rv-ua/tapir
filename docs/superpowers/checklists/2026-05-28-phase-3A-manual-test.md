## Сценарії

### 1. Іконка у треї
- [x] Після запуску `tapir.exe` іконка з'являється в зоні сповіщень
- [x] Наведення миші → tooltip «Tapir»
- [x] NVDA зачитує «Tapir» при фокусуванні іконки (Win+B → стрілки)

### 2. Меню у стані спокою (idle)
- [x] Правий клік → відкривається контекстне меню
- [x] Є пункт «Грати» — **вимкнений** (сірий / недоступний)
- [x] Є пункт «Приховати Tapir» (або «Показати Tapir»)
- [x] Є пункт «Вихід»
- [x] **Немає** пунктів «Зараз грає», «Пауза», «Зупинити», «Записи»
- [x] NVDA зачитує кожен пункт меню

### 3. Меню під час запису
- [x] Запустити запис хоча б однієї станції
- [x] Правий клік → є пункт «● Записи: 1 активних» — **вимкнений**
- [x] Є пункт «Зупинити всі записи» — **активний**
- [x] NVDA зачитує «● Записи: 1 активних»

### 4. Меню під час відтворення
- [x] Запустити відтворення потоку
- [x] Правий клік → є рядок «Зараз грає: {назва станції}» — **вимкнений**
- [x] Є пункт «Пауза» — **активний**
- [x] Є пункт «Зупинити» — **активний**
- [x] Пункт «Грати» **зник** або замінився на «Пауза»/«Зупинити»

### 5. Комбінований стан (відтворення + запис)
- [x] Одночасно відтворення і запис
- [x] Наведення миші → tooltip містить ▶ назву станції і ● кількість записів  
  Очікуваний формат: `Tapir — ▶ {станція} · ● 1 записів`
- [x] Меню містить обидва блоки (відтворення і запис)

### 6. Перемикання видимості лівим кліком
- [x] Вікно відкрите → лівий клік на іконці → **вікно приховується**
- [x] Вікно приховане → лівий клік → **вікно з'являється** і отримує фокус
- [x] Після показу: NVDA оголошує вміст вікна (ActivityBar або остання зупинка фокусу)
- [x] Пункт меню «Приховати Tapir» / «Показати Tapir» змінюється відповідно

### 7. Кнопка «Закрити» при `minimizeToTray = true` (за замовчуванням)
- [x] Alt+F4 або кнопка ✕ → вікно **приховується**, процес продовжує роботу
- [x] Іконка в треї залишається
- [x] Активні записи продовжуються
- [x] Лівий клік на іконці → вікно повертається

### 8. Кнопка «Закрити» при `minimizeToTray = false`
- [x] У налаштуваннях вимкнути «Мінімізувати до трею»
- [ ] Alt+F4 **без активних записів** → **завершення програми** (graceful shutdown + exit), іконка зникає з трею
- [ ] Alt+F4 **з активними записами** → з'являється той самий MessageBox, що й у сценарії 11; поведінка «Так»/«Ні» ідентична виходу через трей
- [ ] «Ні» → вікно лишається відкритим, записи продовжуються, нічого не приховується
- [ ] «Так» → активні записи зупиняються, процес завершується

### 9. Balloon-сповіщення при зміні треку
- [x] Відтворення потоку з ICY-метаданими
- [x] При зміні треку → з'являється balloon: заголовок = назва станції, тіло = «Виконавець — Назва»
- [x] Друга зміна треку **протягом 3 с** → **balloon не з'являється** (throttle)
- [x] Через 3+ с → наступна зміна треку → balloon з'являється знову
- [x] Якщо `showTrayNotifications = false` — balloon не з'являється зовсім

### 10. Клік на balloon
- [x] Balloon відображається
- [x] Клік на balloon → **вікно показується** і отримує фокус
- [x] Якщо вікно вже відкрите — просто отримує фокус

### 11. Вихід з активними записами (через трей-меню)
- [x] Один або більше активних записів
- [x] Трей → «Вихід»
- [x] З'являється **нативний MessageBox**: «Активних записів: N. Вийти з програми і зупинити їх?»
- [x] NVDA автоматично зачитує текст діалогу
- [x] **«Ні»** (за замовчуванням, Enter) → діалог закривається, програма продовжує роботу
- [x] **«Так»** → graceful shutdown + вихід з програми

> **Примітка:** той самий MessageBox має з'являтися й при Alt+F4 з активними записами (див. сценарій 8). Логіка підтвердження спільна для обох шляхів виходу.

### 12. Вихід без активних записів
- [x] Немає активних записів
- [x] Трей → «Вихід» — **жодного MessageBox**, одразу graceful shutdown + вихід
- [x] Alt+F4 (при `minimizeToTray = false`) — також без MessageBox, одразу вихід
- [x] Процес завершується

### 13. Вимкнений пункт «Грати» в стані спокою
- [x] У стані спокою (немає відтворення) відкрити трей-меню
- [x] Навести на «Грати» → не активується при кліку
- [x] Натиснути Enter на «Грати» → нічого не відбувається
- [x] NVDA зачитує «Грати недоступно» або аналог

### 14. Режим Високого Контрасту та NVDA
- [x] Увімкнути High Contrast у Windows (Settings → Accessibility → Contrast themes)
- [x] Відкрити трей-меню → пункти **читабельні**
- [x] NVDA оголошує кожен пункт меню правильно
- [x] Balloon-сповіщення відображається коректно
- [x] MessageBox при виході читається NVDA

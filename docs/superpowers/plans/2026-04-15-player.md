# Player Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Player subsystem — live stream playback, file playback with seek, volume control, output device selection, and a persistent PlayerPanel UI.

**Architecture:** Task-based `PlayerEngine` in Rust (rodio + symphonia), registered in `AppState` alongside `StreamManager`. Live playback uses an independent HTTP connection via existing `stream::connection`; bytes flow through an `rtrb` SPSC ring buffer into a custom `LiveSource` implementing `rodio::Source`. File playback delegates directly to `rodio::Decoder` (symphonia). Frontend: `player.ts` Nanostore + `PlayerPanel` permanent bottom bar.

**Tech Stack:** Rust (rodio 0.22, cpal, rtrb, symphonia via rodio), React 19 + React Aria Components, Nanostores, Tauri IPC events.

```rust
impl PlayerEngine {
    /// Create a new PlayerEngine using the system default audio output device.
    pub fn new() -> Result<Self> {
        let (stream, handle) = OutputStream::try_default()
            .context("Failed to open audio output stream")?;
        Ok(Self {
            session: Arc::new(Mutex::new(None)),
            volume: Arc::new(Mutex::new(0.75)),
            output_device_name: Arc::new(Mutex::new(None)),
            output_stream: Arc::new(Mutex::new(Some(stream))),
            output_handle: Arc::new(Mutex::new(handle)),
        })
    }

    /// Build a PlayerStatus snapshot from current engine state.
    pub async fn get_status(&self) -> PlayerStatus {
        let session = self.session.lock().await;
        let volume = *self.volume.lock().await;
        match session.as_ref() {
            None => PlayerStatus {
                state: PlaybackState::Stopped,
                source: None,
                volume,
                position_ms: None,
                duration_ms: None,
            },
            Some(s) => {
                let pos = s.sink.get_pos().as_millis() as u64;
                let paused = s.sink.is_paused();
                PlayerStatus {
                    state: if paused { PlaybackState::Paused } else { PlaybackState::Playing },
                    source: Some(s.source.clone()),
                    volume,
                    position_ms: Some(pos),
                    duration_ms: s.duration_ms,
                }
            }
        }
    }

    /// Stop and drop the current session if any.
    async fn stop_session(&self) {
        let mut session = self.session.lock().await;
        if let Some(s) = session.take() {
            s.cancel.cancel();
            s.progress_task.abort();
            // Sink stops automatically when dropped
        }
    }
}
```

```rust
impl PlayerEngine {
    pub async fn play_file(&self, path: String, app: &AppHandle) -> Result<()> {
        self.stop_session().await;

        let file = std::fs::File::open(&path)
            .with_context(|| format!("File not found: {path}"))?;
        let reader = std::io::BufReader::new(file);
        let decoder = Decoder::new(reader)
            .context("Unsupported audio format")?;

        let duration_ms = decoder.total_duration().map(|d| d.as_millis() as u64);

        let handle = self.output_handle.lock().await;
        let sink = Arc::new(
            Sink::try_new(&*handle).context("Failed to create audio sink")?
        );
        drop(handle);

        let volume = *self.volume.lock().await;
        sink.set_volume(volume);
        sink.append(decoder);

        let cancel = CancellationToken::new();
        let cancel_clone = cancel.clone();
        let sink_clone = Arc::clone(&sink);
        let app_clone = app.clone();
        let dur = duration_ms.unwrap_or(0);

        let progress_task = tokio::spawn(async move {
            let mut interval = tokio::time::interval(Duration::from_secs(1));
            loop {
                tokio::select! {
                    _ = cancel_clone.cancelled() => break,
                    _ = interval.tick() => {
                        if sink_clone.empty() { break; }
                        let pos = sink_clone.get_pos().as_millis() as u64;
                        let _ = app_clone.emit("player-progress", PlayerProgressPayload {
                            position_ms: pos,
                            duration_ms: dur,
                        });
                    }
                }
            }
        });

        *self.session.lock().await = Some(PlaybackSession {
            sink: Arc::clone(&sink),
            cancel,
            source: PlaybackSource::File { path: path.clone() },
            duration_ms,
            progress_task,
        });

        let status = self.get_status().await;
        app.emit("player-status", status)?;
        info!("Player: playing file {path}");
        Ok(())
    }
}
```

```rust
impl PlayerEngine {
    pub async fn pause_playback(&self, app: &AppHandle) -> Result<()> {
        let session = self.session.lock().await;
        let s = session.as_ref().ok_or_else(|| anyhow!("not playing"))?;
        s.sink.pause();
        drop(session);
        let status = self.get_status().await;
        app.emit("player-status", status)?;
        Ok(())
    }

    pub async fn resume_playback(&self, app: &AppHandle) -> Result<()> {
        let session = self.session.lock().await;
        let s = session.as_ref().ok_or_else(|| anyhow!("not playing"))?;
        s.sink.play();
        drop(session);
        let status = self.get_status().await;
        app.emit("player-status", status)?;
        Ok(())
    }

    pub async fn seek_playback(&self, position_ms: u64, app: &AppHandle) -> Result<()> {
        let session = self.session.lock().await;
        let s = session.as_ref().ok_or_else(|| anyhow!("not playing"))?;

        match &s.source {
            PlaybackSource::Stream { .. } => {
                return Err(anyhow!("seek unavailable for live stream"));
            }
            PlaybackSource::File { .. } => {
                // rodio 0.22: Sink::try_seek delegates to symphonia — no sink recreate needed
                s.sink
                    .try_seek(Duration::from_millis(position_ms))
                    .map_err(|e| anyhow!("seek failed: {e}"))?;
                let pos = s.sink.get_pos().as_millis() as u64;
                let dur = s.duration_ms.unwrap_or(0);
                drop(session);
                app.emit("player-progress", PlayerProgressPayload {
                    position_ms: pos,
                    duration_ms: dur,
                })?;
            }
        }
        Ok(())
    }
}
```

```rust
impl PlayerEngine {
    /// Enumerate system audio output devices. Runs in spawn_blocking because cpal is sync.
    pub async fn list_output_devices() -> Result<Vec<AudioDevice>> {
        tokio::task::spawn_blocking(|| -> anyhow::Result<Vec<AudioDevice>> {
            let host = cpal::default_host();
            let default_name = host.default_output_device()
                .and_then(|d| d.name().ok());
            let devices = host
                .output_devices()
                .context("failed to enumerate audio output devices")?
                .filter_map(|d| {
                    d.name().ok().map(|name| AudioDevice {
                        is_default: Some(&name) == default_name.as_ref(),
                        name,
                    })
                })
                .collect();
            Ok(devices)
        })
        .await
        .context("device enumeration task panicked")?
        .context("device enumeration failed")
    }

    /// Switch audio output device. Stops current playback.
    /// `name` = None means revert to system default.
    pub async fn set_output_device(&self, name: Option<String>, app: &AppHandle) -> Result<()> {
        // 1. Stop current playback
        self.stop_session().await;

        // 2. Open new output stream on requested device
        let (new_stream, new_handle) = tokio::task::spawn_blocking({
            let name = name.clone();
            move || -> anyhow::Result<(OutputStream, OutputStreamHandle)> {
                use cpal::traits::{DeviceTrait, HostTrait};
                let host = cpal::default_host();
                if let Some(ref device_name) = name {
                    let device = host
                        .output_devices()
                        .context("enumerate devices")?
                        .find(|d| d.name().ok().as_deref() == Some(device_name))
                        .with_context(|| format!("device not found: {device_name}"))?;
                    OutputStream::try_from_device(&device).context("open device stream")
                } else {
                    OutputStream::try_default().context("open default stream")
                }
            }
        })
        .await
        .context("device switch task panicked")??;

        // 3. Replace stream and handle
        *self.output_stream.lock().await = Some(new_stream);
        *self.output_handle.lock().await = new_handle;
        *self.output_device_name.lock().await = name;

        // 4. Emit stopped status
        let volume = *self.volume.lock().await;
        app.emit("player-status", PlayerStatus {
            state: PlaybackState::Stopped,
            source: None,
            volume,
            position_ms: None,
            duration_ms: None,
        })?;
        info!("Player: switched output device");
        Ok(())
    }
}
```

Live playback reads audio bytes from an HTTP stream into an `rtrb` SPSC ring buffer. `LiveSource` implements `rodio::Source` by reading from the consumer end and decoding via symphonia.

- [ ] **Step 1: Add LiveSource struct**

Add before `impl PlayerEngine` in `engine.rs`:

```rust
use rtrb::Consumer;
use std::collections::VecDeque;
use rodio::Source;

/// Lock-free SPSC audio source for live HTTP streams.
/// Receives raw audio bytes from the writer task via rtrb Consumer,
/// decodes them in chunks via symphonia, and yields samples to rodio.
struct LiveSource {
    consumer: Consumer<u8>,
    // Decoded PCM samples waiting to be consumed by rodio
    buffer: VecDeque<i16>,
    channels: u16,
    sample_rate: u32,
}

impl LiveSource {
    fn new(consumer: Consumer<u8>, channels: u16, sample_rate: u32) -> Self {
        Self {
            consumer,
            buffer: VecDeque::with_capacity(4096),
            channels,
            sample_rate,
        }
    }

    /// SKELETON — panics loudly if called. Replace with Task 6a implementation.
    fn decode_chunk(&mut self) -> bool {
        use std::sync::Once;
        static WARN: Once = Once::new();
        WARN.call_once(|| {
            panic!(
                "[LiveSource] decode_chunk is a non-functional skeleton that \
                interprets compressed MP3/AAC bytes as raw PCM — this will produce \
                noise or silence. Implement proper symphonia decoding from Task 6a \
                before shipping. See docs/superpowers/plans/2026-04-15-player.md §Task 6a."
            );
        });
        false
    }
}

impl Iterator for LiveSource {
    type Item = i16;
    fn next(&mut self) -> Option<i16> {
        if self.buffer.is_empty() {
            if !self.decode_chunk() {
                return None; // Producer dropped — stream ended
            }
        }
        // Return silence if buffer still empty (data hasn't arrived yet)
        Some(self.buffer.pop_front().unwrap_or(0))
    }
}

impl Source for LiveSource {
    fn current_frame_len(&self) -> Option<usize> { None }
    fn channels(&self) -> u16 { self.channels }
    fn sample_rate(&self) -> u32 { self.sample_rate }
    fn total_duration(&self) -> Option<Duration> { None }
}
```

> **Note:** This is a simplified skeleton. The full implementation requires wrapping symphonia's `FormatReader` around an `rtrb`-backed `Read` implementation to properly decode MP3/AAC frames. The skeleton above shows the structural pattern; the implementer should use symphonia's `mp3::MpaDecoder` / `aac::AacDecoder` with a ring-buffer-backed reader. See symphonia docs for `io::ReadOnlySource`.

- [ ] **Step 2: Implement `play_stream`**

```rust
impl PlayerEngine {
    pub async fn play_stream(
        &self,
        stream_id: String,
        url: String,
        app: &AppHandle,
    ) -> Result<()> {
        self.stop_session().await;

        // Ring buffer: 512 KB — enough for ~3s of 128kbps MP3
        let (mut producer, consumer) = rtrb::RingBuffer::<u8>::new(512 * 1024);

        let cancel = CancellationToken::new();
        let cancel_writer = cancel.clone();
        let url_clone = url.clone();
        let stream_id_clone = stream_id.clone();
        let app_clone = app.clone();

        // Writer task: HTTP → rtrb producer
        tokio::spawn(async move {
            use crate::stream::connection;
            use futures_util::StreamExt;

            match connection::connect(&url_clone).await {
                Err(e) => {
                    error!("Player: connect error for {stream_id_clone}: {e}");
                    let _ = app_clone.emit("player-status", PlayerStatus {
                        state: PlaybackState::Stopped,
                        source: None,
                        volume: 0.75,
                        position_ms: None,
                        duration_ms: None,
                    });
                }
                Ok(conn) => {
                    let mut stream = conn.response.bytes_stream();
                    loop {
                        tokio::select! {
                            _ = cancel_writer.cancelled() => break,
                            chunk = stream.next() => {
                                match chunk {
                                    None => break, // stream ended
                                    Some(Err(e)) => {
                                        warn!("Player: stream error {stream_id_clone}: {e}");
                                        break;
                                    }
                                    Some(Ok(bytes)) => {
                                        // Write bytes to ring buffer
                                        // If buffer is full, drop oldest — prefer freshness
                                        let mut remaining = bytes.as_ref();
                                        while !remaining.is_empty() {
                                            match producer.write_chunk(remaining.len()) {
                                                Ok(mut chunk) => {
                                                    let (head, _) = chunk.as_mut_slices();
                                                    let n = head.len().min(remaining.len());
                                                    head[..n].copy_from_slice(&remaining[..n]);
                                                    remaining = &remaining[n..];
                                                    chunk.commit(n);
                                                }
                                                Err(_) => {
                                                    // Buffer full — skip bytes rather than block
                                                    break;
                                                }
                                            }
                                        }
                                    }
                                }
                            }
                        }
                    }
                }
            }
        });

        // Assume stereo 44100 Hz — LiveSource will be refined with actual ICY headers
        let live_source = LiveSource::new(consumer, 2, 44100);

        let handle = self.output_handle.lock().await;
        let sink = Arc::new(
            Sink::try_new(&*handle).context("Failed to create audio sink")?
        );
        drop(handle);

        let volume = *self.volume.lock().await;
        sink.set_volume(volume);
        sink.append(live_source);

        // No progress task for live streams (position is always "now")
```

```rust
use std::io::{self, Read};

/// Wraps an rtrb Consumer as a std::io::Read.
/// Blocks (spin-yields) until data is available or producer is dropped.
struct RtrbReader {
    consumer: rtrb::Consumer<u8>,
}

impl Read for RtrbReader {
    fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> {
        if buf.is_empty() { return Ok(0); }
        // Spin until data arrives (audio thread — brief spin is acceptable)
        loop {
            let available = self.consumer.slots();
            if available == 0 {
                if self.consumer.is_abandoned() {
                    return Ok(0); // producer dropped — EOF
                }
                std::thread::yield_now();
                continue;
            }
            let n = available.min(buf.len());
            let chunk = self.consumer.read_chunk(n).map_err(|_| {
                io::Error::new(io::ErrorKind::UnexpectedEof, "rtrb read failed")
            })?;
            let (head, tail) = chunk.as_slices();
            let head_n = head.len().min(n);
            buf[..head_n].copy_from_slice(&head[..head_n]);
            let tail_n = (n - head_n).min(tail.len());
            buf[head_n..head_n + tail_n].copy_from_slice(&tail[..tail_n]);
            chunk.commit(n);
            return Ok(n);
        }
    }
}
```

Replace the `LiveSource` struct and its impls from Task 6 with:

```rust
use symphonia::core::audio::{SampleBuffer, SignalSpec};
use symphonia::core::codecs::DecoderOptions;
use symphonia::core::formats::FormatOptions;
use symphonia::core::io::ReadOnlySource;
use symphonia::core::meta::MetadataOptions;
use symphonia::core::probe::Hint;
use symphonia::default::get_probe;

struct LiveSource {
    format: Box<dyn symphonia::core::formats::FormatReader>,
    decoder: Box<dyn symphonia::core::codecs::Decoder>,
    track_id: u32,
    buffer: VecDeque<i16>,
    spec: SignalSpec,
}

impl LiveSource {
    /// Build a LiveSource from an rtrb Consumer.
    /// Probes the stream format (MP3 or AAC) then creates a decoder.
    fn new(consumer: rtrb::Consumer<u8>, hint_mime: Option<&str>) -> anyhow::Result<Self> {
        let reader = RtrbReader { consumer };
        let source = ReadOnlySource::new(reader);
        let mut hint = Hint::new();
        if let Some(mime) = hint_mime {
            hint.mime_type(mime);
        }
        let probe = get_probe()
            .format(&hint, source, &FormatOptions::default(), &MetadataOptions::default())
            .context("could not probe live stream format")?;
        let format = probe.format;
        let track = format.default_track()
            .ok_or_else(|| anyhow!("no default track in live stream"))?;
        let track_id = track.id;
        let decoder = symphonia::default::get_codecs()
            .make(&track.codec_params, &DecoderOptions::default())
            .context("unsupported codec in live stream")?;
        let spec = SignalSpec::new(
            track.codec_params.sample_rate.unwrap_or(44100),
            track.codec_params.channels.unwrap_or_default(),
        );
        Ok(Self { format, decoder, track_id, buffer: VecDeque::new(), spec })
    }

    fn decode_next_packet(&mut self) -> bool {
        loop {
            match self.format.next_packet() {
                Ok(packet) if packet.track_id() == self.track_id => {
                    match self.decoder.decode(&packet) {
                        Ok(decoded) => {
                            let mut samples = SampleBuffer::<i16>::new(
                                decoded.capacity() as u64, self.spec
                            );
                            samples.copy_interleaved_ref(decoded);
                            self.buffer.extend(samples.samples().iter().copied());
                            return true;
                        }
                        Err(e) => {
                            warn!("[decode_next_packet] decoder error (track {}): {e}", self.track_id);
                            continue;
                        }
                    }
                }
                Ok(_) => continue, // different track — skip
                Err(e) => {
                    // symphonia::core::errors::Error::IoError on clean EOF is normal
                    warn!("[decode_next_packet] format reader error: {e}");
                    return false;
                }
            }
        }
    }
}

impl Iterator for LiveSource {
    type Item = i16;
    fn next(&mut self) -> Option<i16> {
        if self.buffer.is_empty() && !self.decode_next_packet() {
            return None;
        }
        self.buffer.pop_front()
    }
}

impl Source for LiveSource {
    fn current_frame_len(&self) -> Option<usize> { None }
    fn channels(&self) -> u16 {
        self.spec.channels.count() as u16
    }
    fn sample_rate(&self) -> u32 { self.spec.rate }
    fn total_duration(&self) -> Option<Duration> { None }
}
```

- [ ] **Step 4: Update `play_stream` to use new `LiveSource::new`**

`conn` is consumed by the writer task closure, so `content_type` must be extracted **before** the writer task is spawned. In `play_stream`, restructure as follows:

```rust
pub async fn play_stream(&self, stream_id: String, url: String, app: &AppHandle) -> Result<()> {
    self.stop_session().await;

    // Connect BEFORE spawning tasks so we can extract content_type
    let conn = connection::connect(&url).await
        .context("failed to connect to stream")?;

    // Extract MIME hint before conn is moved into writer task
    let mime_hint: Option<String> = conn.content_type.clone();

    let (mut producer, consumer) = rtrb::RingBuffer::<u8>::new(512 * 1024);
    let cancel = CancellationToken::new();
    let cancel_writer = cancel.clone();

    // Writer task: reads HTTP body → rtrb producer
    let app_err = app.clone();
    let stream_id_err = stream_id.clone();
    tokio::spawn(async move {
        use futures_util::StreamExt;
        let mut stream = conn.response.bytes_stream();
        loop {
            tokio::select! {
                _ = cancel_writer.cancelled() => break,
                chunk = stream.next() => {
                    match chunk {
                        None => break,
                        Some(Err(e)) => {
                            warn!("Player: stream error {stream_id_err}: {e}");
                            let _ = app_err.emit("player-status", PlayerStatus {
                                state: PlaybackState::Stopped,
                                source: None,
                                volume: 0.75,
                                position_ms: None,
                                duration_ms: None,
                            });
                            break;
                        }
                        Some(Ok(bytes)) => {
                            let mut remaining = bytes.as_ref();
                            while !remaining.is_empty() {
                                match producer.write_chunk(remaining.len()) {
                                    Ok(mut chunk) => {
                                        let (head, _) = chunk.as_mut_slices();
                                        let n = head.len().min(remaining.len());
                                        head[..n].copy_from_slice(&remaining[..n]);
                                        remaining = &remaining[n..];
                                        chunk.commit(n);
                                    }
                                    Err(_) => break, // buffer full — drop bytes
                                }
                            }
                        }
                    }
                }
            }
        }
    });

    // LiveSource::new blocks on RtrbReader until enough bytes arrive for symphonia probing
    // — run in spawn_blocking so we don't block the tokio runtime thread
    let live_source = tokio::task::spawn_blocking(move || {
        LiveSource::new(consumer, mime_hint.as_deref())
    })
    .await
    .context("LiveSource init task panicked")?
    .context("LiveSource init failed")?;

    let handle = self.output_handle.lock().await;
    let sink = Arc::new(Sink::try_new(&*handle).context("failed to create sink")?);
    drop(handle);

    let volume = *self.volume.lock().await;
    sink.set_volume(volume);
    sink.append(live_source);

    let dummy_cancel = cancel.clone();
    let progress_task = tokio::spawn(async move { dummy_cancel.cancelled().await });

    *self.session.lock().await = Some(PlaybackSession {
        sink,
        cancel,
        source: PlaybackSource::Stream { stream_id: stream_id.clone() },
        duration_ms: None,
        progress_task,
    });

    let status = self.get_status().await;
    app.emit("player-status", status)?;
    info!("Player: playing live stream {stream_id}");
    Ok(())
}
```

> **Key fix:** `conn.content_type` is extracted into `mime_hint` before `conn` is moved into the writer task. The writer task captures `conn.response` (and thus `conn`). Without this extraction, the compiler would reject the borrow.

> **Note for Task 6a step 4:** this replaces the entire `play_stream` function from Task 6. Do not apply Task 6's Step 2 writer-task code separately — this is the canonical version.

```tsx
          />
        </SliderTrack>
      </Slider>
    );
  }

  // Live stream — indeterminate progress bar
  return (
    <ProgressBar
      aria-label={m.live_stream()}
      isIndeterminate
      className="flex-1"
    >
      {() => (
        <div className="h-1 w-full rounded bg-slate-600">
```

```tsx
// src/components/player/PlayerPanel.tsx
import { Button } from "react-aria-components";
import { Play, Pause, Square } from "lucide-react";
import { useStore } from "@nanostores/react";
import { $playerStatus } from "../../stores/player";
import { $streams } from "../../stores/streams";
import { PlaybackPosition } from "./PlaybackPosition";
import { VolumeSlider } from "./VolumeSlider";
import { useAnnounce } from "../../hooks/useAnnounce";
import * as tauri from "../../lib/tauri";
import * as m from "../../i18n/paraglide/messages";

function useSourceLabel(): string {
  const { source } = useStore($playerStatus);
  const streams = useStore($streams);
  if (!source) return "";
  if (source.type === "stream") {
    const stream = streams.find((s) => s.id === source.streamId);
    return stream?.name ?? source.streamId;
  }
  // File: show just the filename
  return source.path.split(/[\\/]/).pop() ?? source.path;
}

export function PlayerPanel() {
  const { state } = useStore($playerStatus);
  const sourceLabel = useSourceLabel();
  const announce = useAnnounce();
  const isPlaying = state === "playing";
  const isPaused = state === "paused";
  const isActive = isPlaying || isPaused;

  const handlePlayPause = async () => {
    try {
      if (isPlaying) {
        await tauri.pausePlayback();
        announce(m.playback_paused(), "assertive");
      } else if (isPaused) {
        await tauri.resumePlayback();
        announce(m.playback_resumed(), "assertive");
      }
    } catch (e) {
      console.error(e);
    }
  };

  const handleStop = async () => {
    try {
      await tauri.stopPlayback();
      announce(m.playback_stopped(), "assertive");
    } catch (e) {
      console.error(e);
    }
  };

  return (
    <div
      role="complementary"
      aria-label={m.player_panel_label()}
      className="flex items-center gap-3 px-4 py-2 bg-slate-900 border-t border-slate-700 shrink-0"
    >
      {/* Play/Pause */}
      <Button
        aria-label={isPlaying ? m.pause() : m.play()}
        isDisabled={!isActive}
        onPress={handlePlayPause}
        className="p-1.5 rounded hover:bg-slate-700 focus-visible:ring-2 focus-visible:ring-blue-400 disabled:opacity-40"
      >
        {isPlaying
          ? <Pause aria-hidden size={16} />
          : <Play aria-hidden size={16} />}
      </Button>

      {/* Stop */}
      <Button
        aria-label={m.stop()}
        isDisabled={!isActive}
        onPress={handleStop}
        className="p-1.5 rounded hover:bg-slate-700 focus-visible:ring-2 focus-visible:ring-blue-400 disabled:opacity-40"
      >
        <Square aria-hidden size={16} />
      </Button>

      {/* Source label — live region so NVDA announces track changes */}
      <span
        aria-live="polite"
        aria-atomic="true"
        className="text-sm text-slate-300 truncate flex-shrink-0 max-w-48"
      >
        {sourceLabel}
      </span>

      {/* Position (expands to fill space) */}
      <PlaybackPosition />

      {/* Volume */}
      <VolumeSlider />
    </div>
  );
}
```

## Known Limitations

1. **LiveSource decoding:** The `LiveSource` implementation in Task 6 is a structural skeleton. The sample decoding logic (raw bytes → i16 PCM) needs a proper symphonia `FormatReader` wrapped around an `rtrb`-backed `io::Read` implementation. The skeleton will produce silence until this is properly implemented. Search symphonia docs for `ReadOnlySource` and `ProbeResult` for the correct approach.

2. **HE-AAC:** symphonia does not support HE-AAC (32-64 kbps streams). Recording still works; playback returns an error. Show toast "Формат не підтримується (HE-AAC)".

3. **`PlayerSession` must be `Send`:** Ensure `LiveSource`, `rtrb::Consumer` implement `Send`. `rtrb` consumers are `Send` by design.

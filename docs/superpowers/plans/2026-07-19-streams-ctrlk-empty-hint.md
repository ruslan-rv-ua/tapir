# Ctrl+K Badge in Streams Empty State — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a muted, non-focusable `Ctrl+K` hint badge next to the CTA in the Streams empty state, so the command palette stays discoverable after the visible "Commands" button was removed (ADR 2026-05-31 §6, S3).

**Architecture:** A single inline `<p><kbd>` node appended inside the existing `isEmpty` branch of `StreamsPanel`. The label text comes from a new Paraglide message key; the accelerator string is read from the existing `SHORTCUTS` array so the badge and the F1 help dialog cannot drift apart. No focus management, roving-focus, or zone registration changes.

**Tech Stack:** React 19, TypeScript, Tailwind CSS, Paraglide.js (compile-time i18n), Vitest + Testing Library.

## Global Constraints

- Ukrainian first, English second. Message keys live in `src/i18n/messages/uk.json` and `src/i18n/messages/en.json`.
- Never hand-edit generated files under `src/i18n/paraglide/` — they are regenerated by the `paraglideVitePlugin` in `vite.config.ts` on any vite/vitest run.
- The badge MUST NOT be a Tab stop: no `tabIndex`, no `role`, no `aria-*`, not a `<button>`.
- Every new styled element carries `forced-colors:` variants, matching neighbouring nodes in the empty state.
- Do not touch the `Ctrl+K` engine in `src/App.tsx` or the `SHORTCUTS` array in `src/lib/shortcuts.ts`.
- Do not add the badge to the filter-empty branch (`StreamsPanel.tsx:688-704`).
- Gates: `pnpm test` and `pnpm vite:build` must both pass before the final commit.

```tsx
describe("StreamsPanel — Ctrl+K palette hint badge (ADR 2026-05-31 §6 S3)", () => {
  it("renders the badge with the combo from SHORTCUTS in the empty state", () => {
    $streams.set([]);
    renderPanel();
    const kbd = screen.getByText(PALETTE_COMBO_EXPECTED);
    expect(kbd.tagName).toBe("KBD");
    expect(screen.getByText(/команди —|commands —/i)).toBeTruthy();
  });

  it("the badge is not a Tab stop", () => {
    $streams.set([]);
    renderPanel();
    const kbd = screen.getByText(PALETTE_COMBO_EXPECTED);
    expect(kbd.getAttribute("tabindex")).toBeNull();
    expect(kbd.getAttribute("role")).toBeNull();
    expect(kbd.closest("button")).toBeNull();
    // The empty state exposes exactly one focusable control: the CTA.
    const hint = document.querySelector('[data-zone-id="streams-empty"]')!;
    expect(hint.querySelectorAll("button, [tabindex]").length).toBe(1);
  });

  it("keeps the streams-empty zone focusing the add-examples button", () => {
    $streams.set([]);
    const onZonesChange = vi.fn();
    render(<StreamsPanel onZonesChange={onZonesChange} exitZone={vi.fn()} />);
    const zones = onZonesChange.mock.calls.at(-1)![0] as {
      id: string;
      focus: (d: "forward" | "backward") => void;
    }[];
    zones.find((z) => z.id === "streams-empty")!.focus("forward");
    expect(document.activeElement).toBe(
      screen.getByRole("button", {
        name: /додати приклади потоків|add example streams/i,
      }),
    );
  });

  it("does not render the badge in the filter-empty state", () => {
    // b is idle; filtering to "recording" hides every stream → filter-empty branch.
    $streamFilter.set("recording");
    renderPanel();
    expect(screen.getByText(m.streams_filter_empty())).toBeTruthy();
    expect(screen.queryByText(PALETTE_COMBO_EXPECTED)).toBeNull();
  });
});
```

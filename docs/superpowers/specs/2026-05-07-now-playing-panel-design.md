# Design: Panel «Зараз грає» — рефакторинг

**Дата:** 2026-05-07  
**Файл:** `src/components/player/PlayerPanel.tsx`  
**Статус:** Approved

---

## Проблема

Panel 1 («Зараз грає») у `PlayerPanel` має кілька UX/a11y проблем:

1. **Порожній стан** — коли нічого не грає, всі поля показують «—». NVDA читає «тире тире тире», що беззмістовно.
2. **«Прослуховування»** — статичний текст без змістовної функції перед бітрейтом.
3. **Локальні файли** — `sourceLabel` і `trackDisplay` обидва показують ім'я файлу (дублювання).
4. **Відсутній контекст для файлів** — немає візуального/доступного маркера що це локальний запис, а не стрім.

---

## Рішення

### 1. Порожній стан («Нічого не грає»)

**Поточно:** три рядки з «—» (`sourceLabel`, `trackDisplay`, рядок meta).  
**Нове:** один placeholder-текст «Нічого не грає» (i18n: `player_nothing_playing`) замість усіх трьох рядків.

- Картка отримує `min-height` щоб висота не змінювалась при переключенні станів.
- Placeholder має бути в DOM (не `display:none`) щоб NVDA оголошував зміну через `aria-live="polite"` на `<article>`.
- Рядок meta (бітрейт, LIVE) — `display:none` у порожньому стані.

```
[Зараз грає]
  Нічого не грає          ← italic, muted
```

### 2. Видалення «Прослуховування»

**Поточно:** `<span>{m.player_listening()}</span>` перед бітрейтом.  
**Нове:** видалити. Бітрейт і LIVE-бейдж самодостатні.

```
[Зараз грає]
  Радіо Промінь
  Тіна Кароль — Вдома
  128 kbps  [● LIVE]      ← без «Прослуховування»
```

i18n-ключ `player_listening` — **видалити** з обох мов.

### 3. Локальні файли

**Поточно:**
- Рядок 1 (bold): ім'я файлу (з `useSourceLabel`)
- Рядок 2 (muted): ім'я файлу знову (з `trackDisplay`)
- Рядок meta: «Прослуховування —»

**Нове:**
- Рядок 1: ім'я файлу + бейдж «Запис» (новий компонент `RecordingBadge`, аналог `LiveBadge`)
- Рядок 2: порожній — зарезервовано під майбутні ID3-теги
- Рядок meta: прихований (немає бітрейту для файлів)

```
[Зараз грає]
  interview_2024.mp3  [Запис]
                            ← порожньо (резерв під теги)
```

### 4. `aria-live` для змін треку

Додати `aria-live="polite"` на блок з `sourceLabel` + `trackDisplay`, щоб NVDA автоматично оголошував зміну треку під час прослуховування.

## Доступність (NVDA)

- `aria-live="polite"` на блоці з назвою станції/файлу та треком — NVDA оголошує зміну трека автоматично.
- У порожньому стані: один рядок «Нічого не грає» — жодних зайвих «тире».
- `RecordingBadge` має `aria-label` (повний текст) — NVDA читає «Запис» як слово, не як символ.
- `min-height` на `<article>` — жодних зсувів розмітки при зміні стану.

---

## Поза скоупом

- Індикатор активного запису в Panel 1 — відкладено (буде в Stream Browser / трей).
- ID3-теги для файлів — відкладено до фази, коли з'явиться метадані-парсер.
- Зміни Panel 2 (Керування) і Panel 3 (Вивід) — не торкаємось.

# Sleep Timer — зупинити відтворення/запис через X хвилин

> **Контекст:** «Слухаю радіо перед сном — хочу, щоб програма автоматично зупинилась».
> Відрізняється від Scheduler (той задає точний час доби), тут — «через X хвилин від зараз».

## Опис

Користувач задає інтервал (наприклад, 30 хвилин). Після його завершення Tapir:
- зупиняє активне відтворення (player)
- опціонально зупиняє активні записи

Таймер відображається у UI (залишок часу) і може бути скасований.

## Критерії готовності

- [ ] UI: кнопка або пункт меню «Sleep Timer» у PlayerPanel або тулбарі
- [ ] Вибір тривалості: декілька пресетів (15 / 30 / 60 хв) + довільне значення
- [ ] Відлік залишку часу видимий у UI (в PlayerPanel або StatusBar)
- [ ] По завершенні — зупиняє відтворення; окремий toggle чи аргумент «зупинити також записи»
- [ ] Кнопка «Скасувати таймер» доступна, поки таймер активний
- [ ] NVDA: оголошення «Sleep Timer запущено на X хв», «Sleep Timer — зупинено відтворення»

## Відкриті питання

- Де розмістити кнопку у UI: PlayerPanel, StatusBar, або системний трей-меню?
- Чи зупиняти записи разом з відтворенням, чи тільки відтворення?

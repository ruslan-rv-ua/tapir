# Застосунок ніде не показує ні своєї версії, ні адреси проєкту

> **Контекст:** знайдено під час grilling `help-troubleshooting`, коли писався
> ескалаційний вихід довідки — «зберіть журнал і повідомте про проблему».

## Опис

Версія застосунку існує рівно в одному місці — `src-tauri/tauri.conf.json` (`"version":
"0.1.0"`). У самому інтерфейсі її **немає ніде**: діалогу «Про програму» не існує, у
налаштуваннях рядка з версією немає, у заголовку вікна теж. Пошук по обох файлах
повідомлень (`src/i18n/messages/{uk,en}.json`) не дає жодного ключа про версію, «about»
чи адресу проєкту.

Так само немає **адреси**, куди повідомляти про проблему. `README.md` каже «open an
issue», але README користувач у застосунку не бачить, а вбудована довідка посилань не
має за конвенцією (клік по `http`-посиланню вивів би webview із застосунку — див.
`useWebviewGuard`).

Чому це варте запису: розділ довідки «Якщо нічого не допомогло» веде користувача
покроково — увімкнути детальне логування, перезапустити, повторити проблему, забрати
`data\logs\tapir.log` — і закінчується проханням повідомити про проблему. **Перше, що
питають у такому звіті, — версія**, а взяти її користувачеві нізвідки. Портативність
робить це гострішим: файл `tapir.exe` перейменовують і копіюють, тож «яка у вас збірка»
не відповідає навіть той, хто її завантажив.

## Відкриті питання

- **Де саме.** (а) Рядок у налаштуваннях програми → **Загальні** (найдешевше, живе поруч
  із «Логуванням», куди й так веде довідка); (б) окремий діалог «Про програму»;
  (в) вкладка в довідці. Рекомендація при підйомі — **(а)**: троблшутинг уже приводить
  користувача саме в цей діалог, тож версія опиняється там, де її шукатимуть.
- **Адреса як текст, не як посилання.** Клікабельне посилання в webview — той самий
  клас аварії, від якого стоїть `useWebviewGuard`. Варіанти: показати адресу текстом
  (виділяється й копіюється), або кнопка «Скопіювати», або відкриття у **зовнішньому**
  браузері через шел — механізм для цього вже є (`commands/shell_open.rs`).

## Критерії готовності

Уточнити після рішень вище. Кістяк:

- [ ] Версія застосунку видно з інтерфейсу й читається з `tauri.conf.json`, а не дублюється
      рядком у коді
- [ ] Адреса проєкту доступна з інтерфейсу способом, який **не** виводить webview із
      застосунку
- [ ] Обидві доступні з клавіатури й озвучуються; версія не перетворюється на пастку
      фокуса
- [ ] Якщо `troubleshooting.md` на цей момент уже написаний — ескалаційна позиція
      посилається на нове місце замість загального «на сторінці проєкту»
- [ ] `pnpm test`, `pnpm vite:build` — без помилок

# Назва файлу у заголовку вікна при відтворенні

- **Слаг:** `window-title-file-playback`
- **Тип:** ідея
- **Стан:** ready
- **Зусилля:** S
- **Оновлено:** 2026-06-15
- **Залежності:** Phase 2A (PlayerEngine ✅), Phase 3C (SongsPanel ✅)

## Опис

**Баг:** при відтворенні записаного файлу заголовок вікна лишається `"Tapir"` — назва файлу не відображається, попри увімкнену опцію "Показувати трек у заголовку".

При відтворенні живого потоку заголовок оновлюється (наприклад, `"Тарас Петриненко — Моя земля · Tapir"`). Для файлів умова `playerStatus.source?.type === "stream"` хибна → рядок `"Tapir"` завжди.

**Що є в `PlaybackSource`:** для файлу є лише `path: string` — шлях до файлу. Немає `artist`/`title` напряму.

**Два варіанти виправлення:**

1. **Ім'я файлу з path** (S, без нових IPC): `path.split('\\').pop()?.replace(/\.\w+$/, '')` — показати `"2026-06-15_Радіо Промінь"`. Простий і достатній для орієнтації.

2. **ID3-теги файлу** (M, новий IPC `get_file_metadata(path)`): показати `"Тарас Петриненко — Моя земля"` з реальних тегів. Ідеальний, але дорожчий.

**Рекомендація:** варіант 1 (ім'я файлу) — дешевий і ефективний. ID3 — якщо реальні теги стали важливі.

## Критерії готовності

- [ ] При відтворенні файлу і `settings.showTrackInTitle = true` заголовок вікна показує назву файлу (без розширення і шляху)
- [ ] При зупинці файлу заголовок повертається до `"Tapir"`
- [ ] NVDA: заголовок вікна озвучується при зміні (Windows автоматично)
- [ ] Опція у налаштуваннях ("Показувати трек у заголовку") вмикає/вимикає і для файлів, і для потоків

## Відкриті питання

- Варіант 1 (ім'я файлу) чи варіант 2 (ID3-теги)?
- Якщо варіант 2: новий IPC `get_file_metadata` або вже є щось у `songs_commands`?

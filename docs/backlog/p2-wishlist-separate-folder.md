# Окрема папка для записів із вішліста

> **Контекст:** Треки, що збігли зі списком бажань (wishlist), зараз зберігаються в ту саму папку, що й решта записів. Хотілося б відразу відокремити їх.

## Опис

Додати можливість задати **окрему вихідну папку для wishlist-записів**. Якщо трек зафіксовано через вішліст — файл зберігається у цій папці, а не у стандартній папці профілю.

Конфігурація:
- поле у налаштуваннях профілю або у секції wishlist;
- якщо поле порожнє — поведінка без змін (стандартна папка).

## Критерії готовності

- [ ] У налаштуваннях є поле для вибору папки wishlist-записів.
- [ ] Якщо поле заповнене, wishlist-треки зберігаються у вказану папку.
- [ ] Якщо поле порожнє — поведінка стандартна (без змін).
- [ ] Налаштування зберігається між сесіями.

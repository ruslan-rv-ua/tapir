# F2 — Редагувати потік (Edit Stream shortcut)

- **Слаг:** `f2-edit-stream`
- **Тип:** ідея
- **Стан:** ready
- **Зусилля:** S
- **Оновлено:** 2026-06-15
- **Залежності:** Phase 1 (AddStreamDialog ✅ — використовується для edit режиму)

## Опис

`F2` — стандартний шорткат "перейменувати/редагувати" у Windows (Explorer, VS Code, NVDA списки). Зафіксований у [keyboard-shortcuts.md](../keyboard-shortcuts.md) як запланований, але не реалізований.

Поточний стан: щоб відредагувати потік, треба:
- Shift+F10 → меню → "Edit" (3 кроки)
- Або мишею на рядку → Edit

З `F2`: одна клавіша на вибраному рядку.

**Поведінка:** `F2` на вибраному рядку таблиці потоків → відкрити `AddStreamDialog` в режимі редагування (той самий діалог що і при додаванні, але передається `streamId` і поля заповнені існуючими даними).

## Технічна реалізація

- `useCompositeList.ts` вже обробляє `Delete` через `onKeyDown`. Додати аналогічний case для `F2` → `onAction("edit", streamId)`.
- `StreamList.tsx` — в `handleAction` додати `"edit"` → передати в `StreamsPanel`.
- `StreamsPanel.tsx` — відкрити `AddStreamDialog` з `editStreamId`.
- Реєстр `shortcuts.ts` — `F2` вже є в `SHORTCUTS` як Tier 2′ (ARIA convention) — треба лише wire up.

> Перевірити чи `F2` не зарезервовано як Tier 2′ без реалізації. Якщо є у `RESERVED_WEBVIEW_COMBOS` без обробника — просто додати обробник.

## Критерії готовності

- [ ] `F2` на фокусованому рядку потоку відкриває `AddStreamDialog` в режимі редагування
- [ ] Поля діалогу заповнені поточними даними потоку (URL, назва)
- [ ] Після збереження — потік оновлюється, діалог закривається
- [ ] NVDA: фокус повертається на відредагований рядок після закриття
- [ ] keyboard-shortcuts.md оновлено (позначити як реалізовано)

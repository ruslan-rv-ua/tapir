# Нечіткий пошук у палітрі команд

> **Контекст:** Зараз пошук у палітрі команд працює як звичайний рядковий contains-пошук. Нечіткий пошук (fuzzy) дає релевантні результати навіть при опечатках та неповному введенні.

## Опис

Замінити поточний пошук у палітрі команд на нечіткий (fuzzy match). Наприклад:

- «налшт» → «Налаштування»;
- «playback» → «Запуск відтворення».

Підходящі бібліотеки: [fuse.js](https://fusejs.io/), [uFuzzy](https://github.com/leeoniya/uFuzzy) або власна реалізація на основі Levenshtein/trigram.

Результати сортуються за релевантністю (score).

## Критерії готовності

- [ ] Пошук знаходить команди при неповному або трохи помилковому введенні.
- [ ] Результати відсортовані за релевантністю — найближчий збіг першим.
- [ ] Точний збіг (якщо є) завжди на першому місці.
- [ ] Продуктивність прийнятна (пошук не гальмує при ~100 командах).

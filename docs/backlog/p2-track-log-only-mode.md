# Режим логування назв треків без запису аудіо

> **Контекст:** Іноді потрібно не записувати аудіо, а лише відстежувати, які треки грали на станції — для ведення плей-листа або ручної закупівлі.

## Опис

Додати режим **«Тільки лог треків»**: замість запису аудіо-файлів програма підключається до потоку, відстежує метадані (назва треку, виконавець) і записує їх у текстовий файл (CSV або простий txt з часовою міткою).

Конфігурація:
- окремий перемикач у профілі або у налаштуваннях запису;
- вибір формату файлу (txt, csv);
- вибір вихідного каталогу (або той самий, що й для записів).

## Критерії готовності

- [ ] Є перемикач для ввімкнення режиму «тільки лог».
- [ ] При активному режимі аудіо-файли не створюються.
- [ ] Назви треків (і час) записуються у файл при кожній зміні метаданих.
- [ ] Файл логу зберігається у вказаному каталозі.
- [ ] Формат файлу налаштовується (мінімум txt або csv).

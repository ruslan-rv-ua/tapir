# Відкриті питання беклогу

Зведення **усіх** питань, які треба вирішити перед/під час реалізації записів беклогу.
Зібрано з секцій «Відкриті питання» кожного запису + перехресні рішення, виявлені при
складанні [ROADMAP.md](ROADMAP.md). Питання зібрані станом на **2026-07-23**;
групування за пріоритетом звірено з переоцінкою **2026-08-17**. Записи, заведені після
2026-07-23 (серед них шість P1 із власними «Відкритими питаннями»), тут ще **не** зібрані —
першоджерело кожного лишається у файлі запису.

> Це навігаційний документ (без `p<рівень>-`-префікса), не запис беклогу. Першоджерело
> кожного питання — однойменний файл; тут лише агрегація для одного перегляду.
> Закриті питання з документа вилучаються — прийняті рішення зафіксовані у файлах-записах
> (історія — у git). Залишкові тригери й перед-релізні перевірки з закритих записів — у секції E.

### [command-palette-taxonomy](p3-command-palette-taxonomy.md) (idea, спірна — перевідкрито 2026-07-23, P2 → P3 2026-08-17)
- 🟥 **Категорія-як-`sublabel` — сигнал чи шум?** Заміна контекстного підпису (яка станція) на родовий тег типу («потік») → для NVDA надлишок у кінці кожного рядка. _Схил.: не робити._
- 🟥 **Пункт-навігація замість дії — регрес одноходового сценарію?** Enter лише ставить фокус на рядок замість «набрав → Enter → пише». _Альтернатива: лишити дії, навігацію додати паралельно._
- 🟥 **Дві семантики Enter без груп** (виконати vs перейти) — непередбачувано для скрінрідера; якщо співіснують — потрібне групування.
- 🟥 **Тай-брейкер однойменних потоків (hostname→бітрейт→URL) — YAGNI?** _Схил.: мінімум (лише hostname) або відкласти._

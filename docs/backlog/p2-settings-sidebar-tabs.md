# Дослідження: переорієнтація вкладок налаштувань — ліворуч (вертикально)

> **Контекст:** Ідея — переробити SettingsDialog так, щоб вкладки розташовувались у бічній панелі ліворуч (як у HelpDialog), замість горизонтального рядка зверху. Потребує дослідження доцільності.

## Питання для дослідження

1. **Чи краще для NVDA?** Горизонтальні табпанелі зчитуються як `tablist` з `role="tab"`; вертикальні — той самий ARIA-паттерн. Різниця — напрямок навігації (←/→ vs ↑/↓). Що зручніше для сліпого користувача, особливо зі зростанням кількості вкладок?

2. **Кількість вкладок:** скільки вкладок зараз у SettingsDialog? Якщо 3–4, горизонтальний варіант не переповнений. Якщо більше — вертикальний економить місце по ширині.

3. **Реалізація в React Aria:** `Tabs` RAC підтримує `orientation="vertical"` — переорієнтація CSS + ARIA вбудована. Обсяг змін мінімальний.

4. **HelpDialog як прецедент:** у HelpDialog вертикальні вкладки вже реалізовані й, ймовірно, пройшли NVDA-тест. Використання того самого паттерну дає консистентність.

5. **Візуальна консистентність:** два схожих за структурою діалоги (Settings + Help) з різною орієнтацією вкладок — потенційна невідповідність. Уніфікація виглядає обґрунтованою.

# Налаштування фокуса при відкритті екрана

> **Контекст:** Зараз при переключенні на новий екран фокус потрапляє на тулбар. Частина користувачів хотіла б, щоб фокус одразу йшов на список (основну область).

## Опис

У налаштуваннях додати опцію: **«Фокус при відкритті екрана»** з двома варіантами:

- **Тулбар** (поточна поведінка) — фокус на перший елемент тулбара екрана.
- **Основна область** — фокус на перший елемент списку/таблиці екрана.

Значення за замовчуванням — `toolbar` (зворотна сумісність).

## Критерії готовності

- [ ] Опція присутня у налаштуваннях з двома варіантами.
- [ ] При значенні `list` фокус переміщується на основну область при відкритті екрана.
- [ ] При значенні `toolbar` поведінка залишається незмінною.
- [ ] Опція зберігається між сесіями.

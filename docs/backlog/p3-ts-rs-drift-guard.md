# ts-rs «лише типи»: сторож дрейфу tauri.ts проти Rust у CI

> **Контекст:** хвіст грилінгу [tauri-ts-type-drift](done/p2-tauri-ts-type-drift.md)
> (2026-09-06). Дослідження [tauri-specta-bindings](done/p3-tauri-specta-bindings.md)
> відхилило генератор bindings, поки крейт у RC, і назвало «середній шлях» — лише типи,
> без команд, на стабільному ts-rs, ≈ 2–3 дні. Нотатка 2026-09-06 (розділ D) перевірила
> ts-rs 12 за першоджерелами: перепони, що зупинили specta, тут не діють. Читати
> першим: [нотатку](../notes/tauri-ts-type-drift.md), розділ D.

## Опис

Ручний `tauri.ts` тримається синхронним із Rust лише увагою людини. Аудит 2026-09-05
знайшов дванадцять розбіжностей, накопичених приблизно за місяць; одна виявилась живою
вадою. Запис [tauri-ts-type-drift](done/p2-tauri-ts-type-drift.md) закриває їх і ставить два
Rust-тести на одну структуру з шістдесяти семи — решта лишається без сторожа.

Питання цього дослідження — чи дає ts-rs у режимі «лише типи» механічний сторож дрейфу
за прийнятну ціну, не змінюючи форми типової поверхні фронтенду. Специфіка проти
specta: `Option<T>` у ts-rs іде як `T | null` — саме та конвенція, яку `tauri.ts` уже
тримає; `#[serde(default)]` не робить поле необов'язковим; `u64` за замовчуванням
`bigint`, але є перемикач середовища.

## Питання дослідження

- Чи проходять 28 типів `profile.rs` і `settings.rs` через `#[derive(TS)]` без
  переписування; що саме дають попередження на `deserialize_with` і чи потрібен `#[ts(as)]`.
- Як експортовані файли (по одному на тип) зводяться до порівняння з ручним `tauri.ts`:
  окремий згенерований файл, з якого `tauri.ts` реекспортує, чи звірка «згенероване
  проти закомміченого» без заміни ручного файлу.
- Форма воріт у CI: `cargo test` експортує, `git diff --exit-code` ловить дрейф — чи
  достатньо цього, і як це лягає в наявний пайплайн з `paths`-фільтром.
- Ціна `TS_RS_LARGE_INT=number` для 21 поля `u64`/`usize` і чи потрібне воно взагалі,
  якщо звірка йде лише по формі, а не по типу числа.
- Час на `cargo test` і чи не повторює цей експорт пастку Windows з lib-тестами, що
  згадують `Builder::<Wry>` (нотатка specta).

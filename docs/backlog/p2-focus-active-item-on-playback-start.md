# Автофокус на елементі при старті відтворення

> **Контекст:** Коли починає відтворюватись новий потік або файл, фокус клавіатури залишається там, де він був. Користувачу зі скринрідером незручно — треба шукати активний елемент.

## Опис

Якщо користувач запускає відтворення нового елемента і **поточний активний екран** відповідає типу елемента, автоматично переміщувати фокус на рядок цього елемента:

- Почав відтворюватись потік → якщо відкрито екран потоків → фокус на рядок цього потоку.
- Почав відтворюватись файл → якщо відкрито екран пісень/файлів → фокус на рядок цього файлу.

Якщо відкрито інший екран — нічого не робити.

## Критерії готовності

- [ ] При старті відтворення потоку на екрані потоків фокус переміщується на відповідний рядок.
- [ ] При старті відтворення файлу на екрані пісень фокус переміщується на відповідний рядок.
- [ ] На інших екранах фокус не змінюється.
- [ ] Переміщення фокусу є тихим (не оголошується скринрідером зайвим чином).

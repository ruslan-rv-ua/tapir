# Дослідження: розширення клавіатурних скорочень (F5/F6 та інші)

> **Контекст:** Дослідження доцільності нових шорткатів. Відправна точка — F5/F6 для копіювання/перенесення потоків у інший профіль; але в рамках дослідження варто охопити всі екрани.

## Відправна точка: F5/F6 для потоків

| Ідея | Дія |
|------|-----|
| `F5` | Копіювати виділені потоки в інший профіль |
| `F6` | Перенести виділені потоки в інший профіль |

**Питання:**
- Чи F5/F6 — очікувані клавіші для цих дій (або інші клавіші природніші — Ctrl+C/Ctrl+X за аналогією з файловим менеджером)?
- Copy/Move вже є у `SelectionActionsMenu` та `StreamContextMenu` — чи виправданий окремий шорткат, враховуючи що дії викликають модальний діалог?
- Чи є конфлікт з іншими шорткатами (F5 у браузері = refresh, але Tapir — нативний Tauri-app)?
- Чи доцільно F5/F6 для single-row без виділення?

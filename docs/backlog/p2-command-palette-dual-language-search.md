# Пошук у палітрі команд дублюється двома мовами

> **Контекст:** Користувач може шукати команду будь-якою зручною мовою — рідною або англійською.

## Опис

Кожна команда та пункт навігації у палітрі команд доступна для пошуку як мовою локалі (наразі — українська), так і англійською. Пошуковий рядок мачить по обох варіантах одночасно.

Приклади:
- «відтворити» та «play» → та сама команда;
- «налаштування» та «settings» → той самий пункт.

Реалізація: до кожного запису команди додати `keywords_en` (або зберігати обидва перекладені рядки у пошуковому індексі).

## Критерії готовності

- [ ] Введення команди англійською знаходить результат, навіть якщо локаль — українська.
- [ ] Введення команди мовою локалі продовжує працювати.
- [ ] Дублювання мов не призводить до дублювання рядків у списку результатів.

# Зображення станції у плеєрі

> **Контекст:** UI-покращення плеєра — відображати обкладинку/логотип потоку (станції) зліва у плеєрі.

## Опис

Зліва у рядку плеєра показувати зображення поточної станції:

- фіксований квадрат фіксованої ширини (напр. 48×48 або 64×64 px);
- зображення вписується в квадрат (`object-fit: contain` або `cover`);
- якщо зображення не задано або не завантажилось — заглушка у вигляді іконки (напр. іконка радіо/нот).

Джерело зображення: поле `image_url` (або `favicon_url`) у моделі потоку, якщо таке є; інакше можна завантажувати favicon домену потоку.

## Критерії готовності

- [ ] У моделі потоку (`Stream`) є поле для зображення (або визначено стратегію отримання).
- [ ] Компонент плеєра відображає квадрат із зображенням зліва.
- [ ] Якщо зображення відсутнє або помилка завантаження — відображається іконка-заглушка.
- [ ] Зображення є декоративним (`alt=""` або `aria-hidden`), не заважає роботі зі скринрідером.

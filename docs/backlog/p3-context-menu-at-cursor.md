# Контекстне меню відкривається у місці правого кліка

> **Контекст:** Зараз контекстне меню позиціонується біля кнопки виклику меню. При правому кліку очікується, що меню з'явиться там, де клікнули.

## Опис

При виклику контекстного меню правою кнопкою миші (`contextmenu` event) меню повинно відкриватися у точці кліка (координати `clientX`/`clientY`), а не прив'язуватися до позиції кнопки меню чи елемента.

Поведінка при виклику через кнопку або клавіатуру (`Space`/`Enter` на кнопці меню) — без змін, залишається прив'язаною до кнопки.

Пастка (звірка 2026-10-04): WebView2 шле ту саму подію `contextmenu` і на правий клік, і на клавішу меню, і на `Shift+F10` (`src/hooks/useCompositeList.ts:1098-1100`) — сьогодні всі три відкривають меню рядка одним обробником. Тож «клавіатура без змін» вимагає відрізнити мишу від клавіатури всередині цього обробника, інакше меню з клавіатури теж стрибне в координати, яких немає.

## Критерії готовності

- [ ] `docs/help/` оновлено — або зазначено, що запис видимої поведінки не змінює
- [ ] `contextmenu`-подія перехоплюється на рядках списку.
- [ ] Меню відкривається у координатах курсора миші.
- [ ] Виклик через кнопку меню або клавіатуру — позиція без змін.
- [ ] Меню не виходить за межі вікна (overflow guard).

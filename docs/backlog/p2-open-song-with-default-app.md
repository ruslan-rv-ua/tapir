## Опис

У менеджері записаних файлів (`SongsPanel`) є пункт контекстного меню "Відкрити у провіднику" — показує файл у Windows Explorer з виділенням (`/select`). Але немає можливості **відкрити сам файл** у плеєрі за замовчуванням (Windows Media Player, VLC, тощо).

**Use case:** користувач хоче прослухати файл у своєму звичайному плеєрі (не у Tapir), або перевірити теги у зовнішньому редакторі.

**Поточний стан:** `open_song_in_explorer` відкриває папку з файлом. Відкриття самого файлу — відсутнє.

## Технічна реалізація

**Варіант 1: через cmd `/c start`** (Windows only):
```rust
std::process::Command::new("cmd")
    .args(["/c", "start", "", &path])
    .spawn()
```

**Варіант 2: `tauri-plugin-opener`** (рекомендований — крос-платформна абстракція):
```rust
app.opener().open_path(&path, None::<&str>)?;
```
Crate `tauri-plugin-opener` вже є в проєкті (`Cargo.toml`) — перевірити.

**Безпека:** path — з `Song.path` (довірений, вже збережений файл). Не з user input напряму.

## UI

У `SongsContextMenu` додати пункт "Відкрити у програмі" або "Відтворити у зовнішньому плеєрі" поряд з "Відкрити у провіднику".

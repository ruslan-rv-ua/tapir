# Невідомий формат потоку мовчки стає MP3 — файл отримує чуже розширення

> **Контекст:** знайдено під час grilling `help-troubleshooting`. Tapir знає рівно два
> формати, а третій не відхиляє й не позначає — тихо називає його першим.

## Опис

`AudioFormat` має рівно два варіанти — `Mp3` і `Aac`
([profile.rs:9](../../../src-tauri/src/profile.rs:9)). Розпізнавання йде тільки по
`Content-Type` ([format.rs](../../../src-tauri/src/stream/format.rs)), і все, крім
`audio/mpeg`, `audio/mp3`, `audio/aac`, `audio/aacp`, `audio/x-aac`, `audio/mp4`, дає
`None`.

А далі — мовчазний фолбек:

```rust
let detected_format = format::detect_from_content_type(content_type)
    .unwrap_or(AudioFormat::Mp3);   // manager.rs:663
```

Формат обирає розширення файлу (`recorder.rs:263` → `"mp3"` / `"aac"`), тож станція в
OGG/Vorbis, Opus чи FLAC записується у файл із назвою `…​.mp3`, у якому лежить не MP3.
Такі станції в каталозі є — Браузер станцій має фільтр **Кодек**, і серед його значень
`OGG` присутній нарівні з `MP3` і `AAC`.

Наслідки:

- **Файл бреше про себе.** Провідник, теговий редактор і сторонній плеєр орієнтуються на
  розширення; частина з них просто відмовиться його відкрити.
- **Власний плеєр Tapir його теж не візьме** — rodio зібрано з `symphonia-mp3`,
  `symphonia-aac`, `symphonia-isomp4`, без Vorbis/Opus/FLAC.
- **Ознаки проблеми немає ніде:** ні в рядку потоку, ні в журналі — фолбек беззвучний.
- **Хибний формат розповзається далі за розширення:** він іде в тип тегів
  ([tags.rs:27](../../../src-tauri/src/songs/tags.rs:27) пише ID3v2 у будь-який контейнер) і
  в **назву потоку** ([naming.rs:38](../../../src-tauri/src/naming.rs:38) → «Radio X (MP3 128k)»),
  тобто запікається в профіль, а не лише в ім'я файлу.

Другий викликач тієї самої функції — `probe` при додаванні — веде себе **чесно**: лишає
`Option` ([probe.rs:33](../../../src-tauri/src/stream/probe.rs:33)). Дефект локальний і живе
рівно в одному рядку `manager.rs`.

## Рішення

Розвилку «розширити чи відмовити» закрито 2026-08-31 на користь **відмови**, розгорнутої
в політику: [ADR — Невідомий формат: відмовити, а не вгадати](../../decisions/2026-08-31-refuse-unknown-format-rather-than-guess.md).
Тут — тільки те, що з неї випливає для роботи.

**Чому не «зберігати як є з нейтральним іменем»** (варіант (в) вихідної редакції): записувач
копіює байти, а межа треку — довільний байтовий зсув. MP3 і ADTS-AAC це витримують, **Ogg і
FLAC — ні**: файл без стартової сторінки із заголовками не відкриє жоден декодер. Чесне
розширення дало б не робочий файл, а мовчазне сміття.

Ключові рішення, кожне з яких має свій пункт в ADR:

1. **Докази перед вердиктом.** `Content-Type`, далі магічні байти. Дефолту немає.
2. **Вердикт трійковий**: впізнаний і вміємо / впізнаний, але чужий / невпізнаний. Ім'я
   чужої сім'ї (`OGG`, `FLAC`) існує **для розмови з людиною** і варіанта в `AudioFormat`
   не отримує.
3. **Невпізнане й чуже не записується** — жодного файлу.
4. **Відмова спроби не витрачає** й перепідключення не планує. Поправка до
   [ADR 2026-08-13](../../decisions/2026-08-13-reconnect-attempt-semantics.md), внесена також у
   [CONTEXT.md](../../../CONTEXT.md) §«Перепідключення і спроба».
5. **Одна `detect` — два викликачі**: `probe` теж підглядає перші байти, тож вердикт при
   додаванні дорівнює вердикту при записі.
6. **Мітка сім'ї зберігається в профілі** й живить три речі: носія в рядку, фаст-фейл
   планувальника, коротке замикання Play.
7. **Для Play імплікація однобічна**: не формат ⟹ не заграє; формат ⟹ нічого не обіцяє
   (`AAC+`).

Словник поповнено терміном **«Формат»** ([CONTEXT.md](../../../CONTEXT.md)): межа запису,
трійка станів, мітка інтерфейсу — **«кодек»** (слово «формат» на екрані зайняте форматом
експорту й форматом файлу).

**Записувач не змінюється жодним рядком** — для непідтримуваного ефіру він просто не
створюється.

## Критерії готовності

**Розпізнавання**

- [x] `detect(content_type, first_bytes)` — єдина точка розпізнавання з трійковим вердиктом
- [x] `application/ogg` розпізнається як чужа сім'я (матчер `audio/*` його не бачив)
- [x] Станція **без** `Content-Type`, що шле MP3, і далі записується — її рятують магічні байти
- [x] `detect` і `detect_from_magic_bytes` більше не під `#[allow(dead_code)]`

**Запис**

- [x] Потік із нерозпізнаним або чужим ефіром не створює **жодного** файлу
- [x] Відмова не витрачає спроб і не планує перепідключення
- [x] Коміт даних ефіру (`icy_name`, бітрейт, мітка, `icy_rename`) відбувається **попри** відмову
- [x] Тост називає кодек, коли сім'ю впізнано, і не радить повторити спробу
- [x] Стан потоку **не** стає `Error`

**Носій**

- [x] Сегмент «кодек і бітрейт» показує «128 kbps · OGG · не підтримується» — і з холодного старту

**Планувальник**

- [x] `try_start` читає мітку й повертає `Err` **не з'єднуючись**
- [x] `ScheduleResultReason::UnsupportedCodec` + ключ у [i18n.rs](../../../src-tauri/src/i18n.rs) + рядок в обох локалях
- [x] Вікно не породжує повторних стартів щохвилини, у підсумку — `Missed` із названою причиною

**Додавання**

- [x] Діалог «Додати потік»: попередження, кнопка «Додати попри це», додавання **не блокується**
- [x] Каталог станцій: застереження всередині наявного повідомлення про додавання, без другого тоста
- [x] Діалог імпорту: третій вид рядка замість «✓», галочка **лишається** позначеною

**Відтворення**

- [x] Play на непідтримуваному потоці відмовляє одразу, без 15-секундної проби symphonia

**Довідка**

- [x] Абзац про фільтр **Кодек** у розділі «Станція записується, але не відтворюється» називає
      значення (`MP3`, `AAC`) і каже, що станція з іншим кодеком не запишеться — uk + en.
      Нового розділу немає; стеля en-файлу — 951/1000 слів
- [x] `scheduling.md` і `streams.md` (uk + en) переліками більше не брешуть: четверта причина
      пропуску, четверте попередження діалогу додавання, третій вид рядка імпорту

**Гейти**

- [x] `cargo test`, `pnpm test`, `pnpm vite:build`. Новий ключ i18n `pnpm test` не побачить,
      поки його не згенеровано на диск (`vitest.config.ts` свідомо без paraglide-плагіна)

**Ручні перевірки** (`a11y: false` — нових зупинок фокуса, змін навігації й нових live-поверхонь немає)

1. [x] Рядок непідтримуваного потоку: дійти **стрілками** до сегмента «кодек і бітрейт» — мітка читається
2. [x] Діалог «Додати потік» з OGG-адресою: після попередження фокус **лишається на кнопці підтвердження**
3. [x] Рядок у діалозі імпорту читає третій стан, а не «✓»

## Свідомо не робимо

- **Не розширюємо `AudioFormat`** і не мігруємо файли, вже записані з чужим розширенням
  (релізу не було — постраждалі файли можуть існувати рівно в однієї людини). Причини — в ADR.
- **`AAC+` цим записом не лікується**: він називається й не грає — це
  [he-aac-mf-playback](../p3-he-aac-mf-playback.md) і [mpv-playback-engine](../p3-mpv-playback-engine.md).
- **Сканер Записів і далі вірить розширенню файлу** — правило про ефір, не про файли на диску.

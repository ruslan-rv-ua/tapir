# Звірити решту architecture.md зі станом коду

> **Контекст:** знахідка 2026-09-04 «в проході» під час
> [tech-stack-doc-drift](p2-tech-stack-doc-drift.md). Прецедент і формат звірки —
> [accessibility-doc-audit](p2-accessibility-doc-audit.md). Запис **огрилено**
> (9 раундів), метод змінено проти початкового, результат — ADR і сторож у гейті.

## Що знайшлось

Початковий запис називав §2, §4, §5, §6, §7. Звірка показала, що список неповний і
що найгірше лежить поза ним.

| § | Стан на початок |
|---|---|
| §1 | Посилання на `docs/FRD-navigation.md` — файл видалено |
| §2 | Дерево на 43 файли при **68** у коді; неіснуючий `postprocess/` |
| §4 | 5 полів `AppState` при **10**; `player` не під `RwLock`; писарів немає |
| §5 | П'ять діаграм (не вісім); §5.2 описує механізм, якого не існує |
| §6 | 40 команд при **85**, з них **11 неіснуючих**; 14 подій із 28, 5 вигаданих |
| §7 | Канал плеєра `crossbeam` — у коді `rtrb`; «postprocess queue runner» не існує |
| §8 | **Підсистеми нагляду за диском немає взагалі** — ні подій, ні перевірок, ні автозупинки |
| §9 | 8 варіантів `RadioError` при **14**; збігалось **одне** ім'я — `InvalidUrl` |
| §10 | Сигнатури `Result<PathBuf, String>` — у коді голий `PathBuf`; 8 функцій із 14 відсутні |
| §11 | Цитата `tauri.conf.json`; 60-рядкова копія `rebuild_tray_menu` з хардкодом рядків |
| §12 | Блок під заголовком «Алгоритм», який **не компілюється** (`format!(".", …)`) |
| §13 | Дубль звіреного `accessibility.md`; оголошує неіснуючий «Disk space low» |
| §15 | ASCII-граф із неіснуючим `postproc/` |
| §16 | «Рекомендації щодо подальших документів» — усі три вже існують |

Окрема знахідка: `data-models.md` §5 — **не** канонічний власник IPC-контракту, а
близнюк §6.2 з тією самою підмножиною подій і тими самими фікціями. Винесено в
[data-models-doc-drift](../p2-data-models-doc-drift.md).

## Що зроблено

Метод змінено: замість звірки переліків — **їх зняття**. Документ описує рішення,
межі й інваріанти; перелік замінено вказівником на канонічне джерело.
**1262 → 560 рядків**, нумерація §1–§16 збережена (на «§4» посилається доктрина
писаря в `src-tauri/src/store.rs`).

- Правило записане як [ADR 2026-09-04](../../decisions/2026-09-04-docs-reference-rather-than-quote.md),
  разом із межею: документи **вимог** (`accessibility.md`, `implementation-phases.md`)
  під нього не підпадають, бо невиконана вимога — їхній законний мешканець.
- Додано інваріант **єдиного писаря** в §4 — `store.rs` посилався на §4 як на джерело
  правила, якого §4 не містила.
- Діаграм лишилось **дві** (запис і старт), стеля записана в самому §5. §5.3
  переписано за справжнім `setup()`, з інваріантом «вікно на передньому плані ОС до
  ініціалізації webview, інакше NVDA мовчить» і двома гейтами відкладеного мовлення.
- §5.2 каже протилежне до попереднього: плеєр **не** ділить байти з рекордером.
- Сторож: `build/docsLinks.test.ts` перевіряє, що шлях у бектіках у трьох
  системних документах існує на диску. Обсяг свідомо вузький — записи беклогу й ADR
  називають неіснуючі файли законно.
- `AGENTS.md` і `docs/agents/domain.md` більше не обіцяють у `architecture.md`
  «структуру модулів».
- §8 знято, ризик винесено в [disk-space-monitor](../p2-disk-space-monitor.md).

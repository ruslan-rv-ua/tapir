# Статистика запису — скільки записано, топ станцій

> **Контекст:** Користувач хоче знати, скільки всього він записував і які станції
> використовує найчастіше. Дані вже частково є у `SavedSong` (тривалість, станція).

## Опис

Відображення агрегованої статистики на основі збережених пісень:

- **Загальний час запису** — сума тривалостей усіх збережених файлів
- **Топ-3 (або топ-5) станцій** по загальному часу запису
- **Кількість треків** всього і за поточний профіль
- **Статистика за período** — за поточний день / тиждень / місяць (опціонально)

Відображення — у SettingsDialog (секція «Статистика» або «Загальні») або як окрема
панель у SongsPanel (над / під списком треків).

## Критерії готовності

- [ ] Підрахунок загального часу з `SavedSong.duration_secs` (або `files` у recordings/)
- [ ] Топ-3 станцій за загальним часом запису (з `SavedSong.stream_name`)
- [ ] Відображення у UI з доступними мітками (aria-label на кожному рядку)
- [ ] NVDA: статистика читається послідовно (list або group)
- [ ] Статистика per-profile (не глобальна)

## Відкриті питання

- Де зберігати агреговані дані: обчислювати on-the-fly з `SavedSong` при кожному відкритті
  (простіше, але повільніше при великій бібліотеці) або кешувати в профілі?
- Чи потрібна статистика за período (день/тиждень/місяць), чи достатньо «всього»?

# Ручне тестування — Фаза 2C (SettingsDialog + Global Shortcuts + Window State)

## Передумови

- Білд: `just build-fast` → `src-tauri\target\release-fast\tapir.exe`
- Тестові потоки: див. [test-streams.md](test-streams.md) (потрібен хоча б один доданий потік)
- Скрінрідер: NVDA (рекомендовано), увімкнений перед запуском `tapir.exe`
- ОС: Windows 11
- Аудіо: два пристрої виведення (навушники + колонки, або HDMI) для тестування Audio tab

> Перед сесією: зробити копію `data/settings.json` і `data/profiles/Default.tapirprofile` для відновлення.

## Відомі обмеження (не тестувати як баги)

| Обмеження | Деталі |
|---|---|
| Tray поля disabled | `minimizeToTray` і `showTrayNotifications` — Phase 3A |
| toggle_recording no-op | Без UI для вибору "поточного потоку" хоткей запису нічого не робить |
| Тема light не стилізована | CSS для light theme може бути неповним (основний UI — dark) |
| Paraglide TS7016 | `.js` файли Paraglide не мають `.d.ts` — pre-existing, не впливає на runtime |
